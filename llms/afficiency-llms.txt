# Afficiency

> Afficiency is a New York-based insurtech that designs, digitally underwrites and issues life
> insurance products on behalf of carrier and reinsurance partners, and distributes them through a
> 100% digital, API-first platform. Partners integrate through a hosted white-label storefront, a

## There is no public API contract

Afficiency markets a REST API but does not publish a machine-readable contract or a public reference.
An agent cannot call this API today. Verified 2026-09-12:

- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf or WSDL at any host this record knows.
- `api.afficiency.com` resolves through Cloudflare but the origin does not answer anonymous requests
  (HTTP 522 on every path probed).
- `support.afficiency.com`, which the company names as the home of its documentation, is a HubSpot
  portal that returns HTTP 404 to anonymous clients on every path including its root.
- Every `/.well-known/` path returns 404 on every host. No agent card, no MCP server, no OAuth
  metadata, no api-catalog.
- No SDK exists in npm, PyPI, RubyGems, crates.io, NuGet or Packagist. The GitHub organization
  named "Afficiency" has zero public repositories.

The route to API access is a sales conversation: https://www.afficiency.com/book-a-demo/

## Integration

- [How Afficiency Can Work With You](https://www.afficiency.com/how-afficiency-can-work-for-you/):
  the three integration models.
  - **White Label** — turnkey, hosted and managed by Afficiency; agent-led eApp, agent and consumer
    portals, end-to-end quote to policy issue, minimal technical requirements.
  - **API Integration** — REST API suite, end-to-end quote to policy issue, fully custom branding,
    the customer stays on the partner's platform, partner retains data ownership.
  - **Hybrid** — partner-built UX for part of the journey, link out to Afficiency for the rest.
- [Embedded Insurance](https://www.afficiency.com/embedded-insurance/): endpoints are described as
  covering quoting, underwriting, policy issuance and administration.
- Distribution channels: [Agencies](https://www.afficiency.com/life-insurance-agencies/),
  [Worksite](https://www.afficiency.com/afficiency-for-worksite/),
  [Affinity](https://www.afficiency.com/afficiency-for-affinity/),
  [P&C](https://www.afficiency.com/property-casualty-agents-agencies/),
  [Financial Advisors](https://www.afficiency.com/financial-advisors/).
